## 前端工程化 / Frontend Engineering

前端工程化旨在通过工具链提升开发效率、代码质量与构建性能。本分类记录主流工程化工具的使用与原理。

!!! note
    工程化工具更新较快，建议关注官方文档获取最新 API。

### 涵盖内容

- **Vite** —— 基于 ESM 的新一代构建工具
- **Webpack** —— 老牌模块打包器，生态成熟

```bash
# 使用 Vite 初始化项目
npm create vite@latest my-app -- --template react-ts
```
