## 后端开发 / Backend Development

后端开发分类整理了服务端开发的技术栈，从框架选型到中间件集成，覆盖常见业务场景。

!!! note
    本站偏向 Java (Spring Boot) 与 Node.js 两大技术栈。

### 子分类

- [Spring Boot](springboot/index.md) —— Java 企业级开发
- [Node.js](nodejs/index.md) —— JavaScript 后端运行时
